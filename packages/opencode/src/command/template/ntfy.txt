## Configuration

ntfy is a push notification service. You can:
- Post notifications to any ntfy server via HTTP POST
- Use the ntfy tool to send messages to configured channels
- Default server: https://ntfy.sh
- Topic names are channel identifiers (e.g., "alerts", "deployments")
