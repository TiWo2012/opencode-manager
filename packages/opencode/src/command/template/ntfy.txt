## What to do

1. If the user provides a message, send it using the ntfy tool.
2. If the user wants to configure a server, edit their opencode.jsonc under the `"ntfy"` section with server URL, topic, and optional auth.
3. The ntfy tool reads server configuration automatically from opencode.jsonc — no need to pass url, topic, or auth manually.

## Configuration

ntfy is a push notification service. To use it, add a server to your opencode.jsonc:

```jsonc
{
  "ntfy": {
    "enabled": true,
    "servers": {
      "home": {
        "url": "https://ntfy.example.com",
        "topic": "my-channel",
        "auth": "Basic dXNlcjpwYXNz"
      }
    }
  }
}
```

## Auth formats

- Basic Auth: `"Basic <base64(username:password)>"`
- Bearer token: `"Bearer tk_abc123"`

## Usage

The ntfy tool only needs:
- `message` (required) — what to send
- `title` (optional) — notification title
- `topic` (optional) — override the configured topic
- `server` (optional) — pick a named server from config (defaults to the first one)
